# 百度指数查询工具发行文件

当前修复版是 v2.4.4，发行包位于 `v2.4.4` 子目录，也可从 [GitHub Releases](https://github.com/Ecow0ker/baidu-index-tool/releases/tag/v2.4.4) 下载。

- macOS Intel：`baidu-index-tool-v2.4.4-macos-x64.zip`。
- macOS M 系列：`baidu-index-tool-v2.4.4-macos-arm64.zip`。
- Windows 64 位：`baidu-index-tool-v2.4.4-windows-x64.exe`。

macOS 首次启动若提示来源限制，可右键 APP 选择“打开”；也可执行：

```bash
xattr -dr com.apple.quarantine /Applications/百度指数查询工具.app
```

大体积二进制文件请作为 GitHub Release assets 上传。
